# Three coherent aesthetic directions

All three preserve LUC's “quiet at rest, alive on interaction, memorable at the moment of interaction” contract in [DESIGN_SYSTEM.md](../../../DESIGN_SYSTEM.md) and [MOTION_GUIDE.md](../../MOTION_GUIDE.md). They are candidate treatments for one test composition, not parallel themes or a proposal to multiply component variants. Existing cool neutral/cyan semantics and tabular numeric text remain recognizable. Each direction should be evaluated in both light and dark before choosing one.

| Attribute | 1. Precision Instrument | 2. Editorial Research | 3. Focused Workspace |
| --- | --- | --- | --- |
| Core idea | A calibrated instrument panel: exact marks, deliberate affordances, nearly silent chrome. | A research publication with interactive evidence: typography leads, data supports the claim. | A desktop analytical workspace: tools recede until selection makes a task explicit. |
| Typography | Keep Inter/Inter Tight/JetBrains Mono from [tokens.css](../../../packages/ui/src/tokens/tokens.css); tighten hierarchy through size and weight, not all-caps labels. Numeric values align in tabular figures. Inspired by [Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md): type should be chosen for the subject, avoiding template treatments. | Give findings a larger, quieter text measure and generous line spacing; compact numeric evidence retains mono/tabular forms. Avoid decorative serif by default: the existing LUC font system already conveys technical credibility. [Anthropic typography guidance](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md); [LUC typography](../../../DESIGN_SYSTEM.md). | Compact headings and high-information labels, with consistent control and row height rather than smaller type. [LUC density rule](../../../DESIGN_SYSTEM.md), [AG Grid professional interactions](https://www.ag-grid.com/react-data-grid/key-features/). |
| Color | Cool neutral canvas; one cyan accent for focus, selection and action; status colors retain semantic labels. [LUC tokens](../../../packages/ui/src/tokens/tokens.css), [Radix state styling](https://www.radix-ui.com/primitives/docs/guides/styling). | Mostly neutral ink and a cyan editorial rule that connects a finding to its evidence. No gradient wash. [LUC accent rule](../../../DESIGN_SYSTEM.md), [Anthropic structural cues](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md). | Cyan is concentrated on the active object and keyboard focus. Inactive panes are neutral, not dimmed with whole-shell opacity. [LUC tokens](../../../packages/ui/src/tokens/tokens.css), [Radix state styling](https://www.radix-ui.com/primitives/docs/guides/styling). |
| Surface hierarchy | Canvas → work surface → inset measurement well; depth by luminance and 1px edge. Test a clearer light-theme step because white default/raised/overlay currently coincide. [LUC gap audit](../../audits/2026-10-productization-gaps-and-consumers.md), [Radix unstyled model](https://www.radix-ui.com/primitives/docs/guides/styling). | Prose stays flat. Only chart, table and evidence objects receive a surface, honoring Luc Web's existing three-level composition. [LUC gap audit](../../audits/2026-10-productization-gaps-and-consumers.md), [shadcn composition](https://ui.shadcn.com/docs). | Pane boundaries and resize handles establish structure; a selected detail panel rises one level. [Workspace](../../../packages/ui/src/workspace/index.ts), [MUI X grid](https://mui.com/x/react-data-grid/). |
| Border and elevation | Hairline rules, calibrated tick marks and restrained inset edge. Shadows only for floating controls. [LUC surface/elevation rules](../../../DESIGN_SYSTEM.md), [Radix styling](https://www.radix-ui.com/primitives/docs/guides/styling). | Section rules and typographic spacing replace extra card borders; overlays remain opaque with token shadow. [LUC design system](../../../DESIGN_SYSTEM.md), [Anthropic structural guidance](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md). | Persistent pane separators; actionable rows get one border/surface step on hover; selected row holds an opaque state. [DataTable](../../../packages/ui/src/table/data-table.tsx), [Radix state styling](https://www.radix-ui.com/primitives/docs/guides/styling). |
| Component silhouettes | 8px controls, 12px cards, 16px overlay; precise rectangular alignment. [LUC radii](../../../DESIGN_SYSTEM.md), [shadcn docs](https://ui.shadcn.com/docs). | Flat section headers; a featured evidence surface uses the existing 12px card silhouette, not an oversized pill. [Card](../../../packages/ui/src/components/card.tsx), [Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md). | Existing AppShell, sidebar rail and split panes define geometry; no floating dock. [AppShell](../../../packages/ui/src/app-shell/index.ts), [Workspace](../../../packages/ui/src/workspace/index.ts), [AG Grid](https://www.ag-grid.com/react-data-grid/key-features/). |
| Motion personality | A crosshair or selected mark responds immediately; a tooltip settles in 140–200ms. No ambient loop. [LUC motion tokens](../../MOTION_GUIDE.md), [Motion Primitives](https://motion-primitives.com/docs/morphing-dialog). | One user-triggered transition from finding to evidence. Reveal content remains readable from first paint; reduced motion is an instant state change. [LUC motion tiers](../../MOTION_GUIDE.md), [Anthropic motion guidance](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md). | Selection drives a coherent pane/row/highlight response. Shared geometry is reserved for detail focus in wide layouts; functional transitions only in dense views. [MorphingDialog](../../../packages/ui/src/motion/morphing-dialog.tsx), [Motion Primitives](https://motion-primitives.com/docs/morphing-dialog). |
| Data visualization | Fine grid, explicit axes, strong visible-at-rest marks, precise tooltip and reference bands. [Chart Guide](../../CHART_GUIDE.md), [MUI X data display](https://mui.com/x/react-data-grid/). | Chart acts as evidence: caption, key finding, then plot/table alternate and method disclosure. [ChartDataTable](../../../packages/ui/src/charts/components/chart-data-table.tsx), [shadcn documentation pattern](https://ui.shadcn.com/docs). | Chart and table share a selection/pin, with inspector context and export grouped by task. No new computation in the UI package. [Chart inspection](../../../packages/ui/src/charts/core/inspection.tsx), [AG Grid interaction model](https://www.ag-grid.com/react-data-grid/key-features/). |
| Light/dark parity | Same depth ordering and selected meaning; use measured luminance/border contrast in both themes. [tokens.css](../../../packages/ui/src/tokens/tokens.css), [Radix styling](https://www.radix-ui.com/primitives/docs/guides/styling). | Same reading order, text hierarchy and chart semantics in both; avoid an editorial light mode paired with a neon dark mode. [LUC chart color rules](../../../DESIGN_SYSTEM.md), [Anthropic subject specificity](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md). | Same pane and focus relationships in both; dark inset highlights and light hairlines each remain perceptible. [LUC elevations](../../../DESIGN_SYSTEM.md), [MUI X theming](https://mui.com/x/). |

**Best first candidate: Focused Workspace.** It exercises the largest real LUC differentiator—data, chart, shell, workspace and motion together—while exposing state and light/dark problems. Precision Instrument can inform its microdetails; Editorial Research is a valuable second experiment for a research narrative. The choice follows the existing [workspace and data gaps](../../audits/2026-10-productization-gaps-and-consumers.md) and professional-grid interaction references ([AG Grid](https://www.ag-grid.com/react-data-grid/key-features/), [MUI X](https://mui.com/x/react-data-grid/)).
