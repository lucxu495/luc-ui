## Cross-library observations

- **Typography and spacing:** shadcn's consistency is a documentation and composability lesson, while Anthropic's [frontend design guidance](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md) warns against default template typography. LUC already has a 4-point spacing scale, Inter/Inter Tight/JetBrains Mono roles, and tabular numeric text in [tokens.css](../../../packages/ui/src/tokens/tokens.css). Distinctiveness should come from typographic *hierarchy and data formatting*, not a wholesale font swap.
- **Surface and elevation:** Radix leaves styling to the system; LUC's six semantic surfaces and dark-mode luminance steps are an asset. The light-theme default/raised/overlay surfaces are all white, so test whether borders alone create enough hierarchy in a dense workspace before altering tokens. [LUC gap audit](../../audits/2026-10-productization-gaps-and-consumers.md), [Radix styling](https://www.radix-ui.com/primitives/docs/guides/styling).
- **Hover, focus, press, selection:** the best systems make these four different states legible. LUC has components and tokens, but [SegmentedControl](../../../packages/ui/src/components/segmented-control.tsx), [Tabs](../../../packages/ui/src/components/tabs.tsx), and [SharedHighlight](../../../packages/ui/src/motion/shared-highlight.tsx) can drift in track geometry or semantics. Radix's exposed state model is useful for a consistent state matrix. [Radix styling](https://www.radix-ui.com/primitives/docs/guides/styling).
- **Motion:** Motion Primitives, Magic UI and Aceternity provide excellent examples of user-triggered delight. LUC already has enough effects; the useful addition is choreography for a *task* (select row → reveal context, pin datum → compare, confirm → settle), bounded by [LUC motion tiers](../../MOTION_GUIDE.md). [Morphing Dialog](https://motion-primitives.com/docs/morphing-dialog), [Magic UI components](https://magicui.design/docs/components), [Aceternity catalog](https://ui.aceternity.com/explore).
- **Professional data UI:** MUI X and AG Grid demonstrate that editing, range selection, export and grouping are a separate interaction and accessibility contract. Improve LUC's read/inspect workflow around [DataTable](../../../packages/ui/src/table/index.ts) and [ChartDataTable](../../../packages/ui/src/charts/components/chart-data-table.tsx) first. [MUI X](https://mui.com/x/react-data-grid/), [AG Grid](https://www.ag-grid.com/react-data-grid/key-features/).
