## Recommended first visual experiment

**Focused Workspace: linked selection to evidence**, as a *design exploration artifact in a future task*, using existing LUC primitives only. Start with the existing [research workspace Showcase composition](../../../apps/showcase/app/patterns/research-workspace/page.tsx) as the visual context and a neutral, prepared dataset. The proposal is to compare the resting view with a selected table row or pinned chart datum: the selected object gains a precise cyan rule, the chart/table share the same identity, and an InspectorPane reveals context. A single user-triggered transition connects selection to detail; reduced motion jumps directly to the settled state. This responds to [MUI X's inspectable grid model](https://mui.com/x/react-data-grid/) and [Motion Primitives' contextual transition](https://motion-primitives.com/docs/morphing-dialog), while exercising LUC's current [Workspace](../../../packages/ui/src/workspace/index.ts), [DataTable](../../../packages/ui/src/table/index.ts) and [chart inspection](../../../packages/ui/src/charts/core/inspection.tsx).

### Small measurable plan

1. **Baseline, 0.5 day:** capture the current Showcase composition at 1440px and 390px, light/dark, rest/hover/focus/selected, plus reduced motion. Record a keyboard path and computed contrast for selected row, pane labels and chart tooltip. Use the current [QA workflow](../../QA_WORKFLOW.md) and [Radix accessibility guidance](https://www.radix-ui.com/primitives/docs/overview/introduction). This research task does not run that baseline.
2. **Three static treatments, 0.5–1 day:** draw the same content in Precision Instrument, Editorial Research and Focused Workspace without modifying production tokens or APIs. Score hierarchy, scan speed, one-accent discipline and theme parity from screenshots. [Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md) motivates subject-specific typography; compare against [LUC tokens](../../../packages/ui/src/tokens/tokens.css).
3. **One interaction prototype, 1–2 days:** implement only the chosen treatment in an isolated future exploration branch or artifact using existing public LUC imports. Measure selection-to-detail completion, keyboard focus return, Escape, reduced-motion path, resize stability and whether all facts are visible without hover. [Motion Primitives](https://motion-primitives.com/docs/morphing-dialog) motivates the continuity; [LUC motion rules](../../MOTION_GUIDE.md) set the budget.
4. **Decision gate, 0.5 day:** accept a direction only if it improves a five-person task check (find and compare two observations; median time and errors versus baseline), passes axe with no new serious/critical findings, keeps text/selected contrast at required levels, avoids layout shift during selection, and holds chart-only bundle isolation. For any future code change use [LUC QA workflow](../../QA_WORKFLOW.md), [consumer test](../../../packages/ui/scripts/consumer-test.mjs), and [Vercel performance guidance](https://github.com/vercel-labs/agent-skills/blob/main/skills/react-best-practices/SKILL.md). If it does not clear the gate, retain the current UI and document what failed.

No installation, package change, component edit, Showcase edit or Luc Web edit is part of this research deliverable.
