# LUC UI design opportunity matrix

Evidence is linked in each row. “Gap” distinguishes an absent capability from an existing primitive that needs a better composition or proof. Estimates are relative: effort / continuing maintenance = L, M, H. Proposed interpretations are original LUC work, not upstream source copies. No implementation is authorized by this study.

| External pattern and why it matters | LUC counterpart; need and meaningful gap | Original LUC interpretation | Effort / maintenance; performance and accessibility |
| --- | --- | --- | --- |
| [Radix state styling](https://www.radix-ui.com/primitives/docs/guides/styling) makes open, selected and disabled state externally legible. | [Input](../../../packages/ui/src/components/input.tsx) and [Select](../../../packages/ui/src/components/select.tsx) share chrome; [Combobox](../../../packages/ui/src/components/combobox.tsx) duplicates part of it. LUC meets the functional need; visual parity across focus, invalid, disabled and read-only is unproven. | One documented state grammar and small source-level visual fixture for all three, then extract only a shared recipe that actually reduces drift. | M/M. CSS state changes should have negligible runtime cost; test focus visibility, label contrast and 200% zoom. |
| [shadcn compositional consistency](https://ui.shadcn.com/docs) makes variants predictable without making each consumer invent defaults. | [Card](../../../packages/ui/src/components/card.tsx) has rich surfaces but legacy `interactive`/`selected` overlaps `interaction`. Need is met; precedence and native actionable semantics are unclear. | Define static, actionable, selectable and featured examples with exact native element contracts. Deprecation is optional after consumer evidence. | L/L–M. No bundle cost; native `<a>`/`button` improves keyboard and focus behavior. |
| [Motion Primitives shared geometry](https://motion-primitives.com/docs/morphing-dialog) makes a selected item and its detail view feel continuous. | [MorphingDialog](../../../packages/ui/src/motion/morphing-dialog.tsx) already exists. Gap is a generic data-inspection recipe using it, [Workspace](../../../packages/ui/src/workspace/index.ts), and [DataTable](../../../packages/ui/src/table/index.ts). | Let a row selection open a contextual evidence view, with an optional morph only in a spacious layout; use Sheet/InspectorPane in dense layouts. | M/M. Measure layout/reflow; preserve focus return, Escape and immediate reduced-motion state. |
| [MUI X](https://mui.com/x/react-data-grid/) and [AG Grid](https://www.ag-grid.com/react-data-grid/key-features/) provide mature discoverable data interactions. | [DataTable](../../../packages/ui/src/table/data-table.tsx) already supports reading, selection, filters and virtualization. Editing/range selection is absent by design, so no duplicate `DataGrid` yet. Gap is the path from selected row to comparison/evidence. | Two generic examples: table → detail pane and chart → corresponding table row. Keep selected identity controlled and shareable via [URL state](../../../packages/ui/src/url-state/index.ts) only when meaningful. | M/M. Keep heavy chart imports isolated; preserve native table semantics and visible selection beyond color. Full grid would be H/H. |
| [Vercel interface guidelines](https://github.com/vercel-labs/web-interface-guidelines) emphasize correct semantics and focus in interface review. | [SharedHighlight](../../../packages/ui/src/motion/shared-highlight.tsx) uses tablist semantics with link/pressed-button children in the current audit. It may be a mismatch; no violation was confirmed by browser QA. | Distinguish navigation links, pressed-button selectors and actual tabs in API/examples. Validate the accessibility tree before any code change. | M/L. No performance cost; high potential a11y gain if mismatch confirmed. |
| [shadcn registry/documentation model](https://ui.shadcn.com/docs/registry/getting-started) makes public capabilities discoverable. | LUC [public API](../../PUBLIC_API.md), [inventory](../../COMPONENT_INVENTORY.md), Showcase, and barrels overlap; audit found drift such as `Button.asChild`. Need is met but source-of-truth is diffuse. | Generate a public catalog from export paths and annotations; keep runnable examples in Showcase and semantic “when to use” notes in one place. | M/L. Build-time cost only; avoids incorrect imports and inappropriate components. See existing [blueprint](../../audits/2026-10-productization-blueprint.md). |
| [Motion Primitives](https://motion-primitives.com/docs/morphing-dialog) and [Magic UI](https://magicui.design/docs/components) show strong moment-to-moment choreography. | [Motion Guide](../../MOTION_GUIDE.md) and [motion barrel](../../../packages/ui/src/motion/index.ts) already define many effects and reduced-motion behavior. Gap is choice guidance, not another effect. | Create a “rest → intent → response → settled” recipe for selection, disclosure and save, allowing one micro-delight per view. | L/L. Reuse existing primitives; cap concurrent animations and test reduced motion/coarse pointer. |
| [Radix unstyled foundation](https://www.radix-ui.com/primitives/docs/overview/introduction) supports skinning without trading away interaction behavior. | LUC dark surfaces step in luminance, but light default/raised/overlay share white in [tokens.css](../../../packages/ui/src/tokens/tokens.css). Need exists; depth may be weak in light theme. | Compare one dense workspace in both themes before trying a subtle light-surface edge/luminance treatment. Keep opaque overlays and hairline borders. | M/L. Token-only trial is cheap; verify contrast and nested-surface legibility. |
| [AG Grid modular loading](https://www.ag-grid.com/react-data-grid/installation/) highlights the cost of professional data machinery. | LUC already isolates chart engines via [chart entries](../../../packages/ui/src/charts/index.ts) and the [consumer test](../../../packages/ui/scripts/consumer-test.mjs). No gap in a general grid dependency is established. | Include bundle and responsiveness checks in every proposed inspection recipe; load charts only when displayed. | L/L. Protects interaction latency; ensure no empty/hidden chart creates an inaccessible island. |
| [Aceternity focus cards](https://ui.aceternity.com/explore) draw attention to one chosen object. | LUC [Card](../../../packages/ui/src/components/card.tsx), [BorderGlow](../../../packages/ui/src/motion/border-glow.tsx) and [DataDetails](../../../packages/ui/src/data/data-details.tsx) meet the visual mechanism. Missing is an explicit “chosen research evidence” pattern. | Give one evidence object an accent rule and precise context label after user selection; leave surrounding data quiet and fully readable. | L/M. Little runtime work if CSS only; never hide information behind hover or pointer tracking. |

## Boundaries that keep the framework distinctive

Do not put Luc Quant Signals, research narrative, calculated indicators or provider content into `@luc/ui`; those remain consumer data and domain composition. [LUC current-state audit](../../audits/2026-10-productization-current-state.md), [Luc Web gap audit](../../audits/2026-10-productization-gaps-and-consumers.md). A premium framework here is a reliable analytical canvas with exact feedback, not a collection of copied spectacle.
