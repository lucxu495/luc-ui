The official sources above show active upstream repositories at the pinned revisions, but this is a source snapshot, not a promise of future maintenance. Codex supports directory-based Skills with `SKILL.md` and optional supporting files; see [OpenAI's Skill description](https://developers.openai.com/plugins/concepts/skills). Vercel's [Skills CLI documentation](https://github.com/vercel-labs/skills/blob/main/README.md) describes Codex installation, but a CLI invocation would write outside this task's allowed paths and may fetch mutable content. It was not run.

## Separate authorized installation task

1. Choose a destination with the user: repository-local Codex Skills (for repeatable team use) or a user's global Codex Skills directory. Both destinations are outside this task's write ownership.
2. Obtain the two upstream repositories at the exact SHAs above using reviewed Git tooling or pinned archive URLs; verify the checked-out commit and inspect every file being copied. Do not run repository scripts or `npx skills add`.
3. Copy only Anthropic `frontend-design/SKILL.md` and `LICENSE.txt` into a dedicated Skill directory. Keep the license text and source SHA with the copy. Confirm Codex discovers the Skill and that its instructions remain subordinate to `.context`, LUC design rules and task instructions.
4. Keep the two Vercel Skills as links/references for now. If a local web-guidelines Skill is later wanted, pin and review `web-interface-guidelines/command.md` separately, resolve the license, then author a small local wrapper that reads the pinned reference. If composition guidance is installed, include the full referenced rule set, preserve license attribution, and do not replace shared `AGENTS.md`.
5. Record update cadence and re-review upstream diffs before changing pins. Installation, global configuration, and policy edits need a separate task with explicit write ownership.

Design guidance actually applied here: deliberate typography and interaction-led motion from [Anthropic](https://github.com/anthropics/skills/blob/683bc88e56f3e09ba94f7055977f3d3aa499f202/skills/frontend-design/SKILL.md), browser accessibility and responsive review from [Vercel's guidelines](https://github.com/vercel-labs/web-interface-guidelines), and one controlled selection state shared among composed public primitives, consistent with [Vercel's composition guidance](https://github.com/vercel-labs/agent-skills/blob/063bee94c3f4df8453406c830b0a7df0f2860278/skills/composition-patterns/SKILL.md).
