# LUC UI V0.3 — open-source audit

Scope: the DataTable, Select, Combobox, Toast, Sheet and CommandMenu round.

Status: repository metadata and licenses verified **2026-09-26** through the
GitHub API (`/repos/<owner>/<repo>` → `license.spdx_id`, `stargazers_count`,
`pushed_at`, `archived`) and through the npm registry for the packages actually
installed. Every package below is also checked against the installed
`package.json` at build time.

This is an engineering assessment, **not legal advice**. Where the license is
ambiguous the row says so and nothing is copied.

## Classification legend

| Class | Meaning |
| --- | --- |
| `DIRECT_DEPENDENCY` | Installed. We use the published public API and ship the package's own license notice. |
| `REFERENCE_ONLY` | Read for architecture, behaviour or documentation. No code, no dependency. |
| `REIMPLEMENT_IDEA` | Behaviour studied; LUC implementation written from scratch. |

## What we learned, and where it went

**Virtualisation must not cost semantics (React Spectrum, Glide).** Both make it
clear that a virtualised table either keeps real row elements or stops being a
table. LUC renders real `<tr>`s and two hidden spacer rows, so `role="row"`,
text selection and find-in-page survive. Glide made the opposite choice
deliberately, which is what confirmed the DataTable/DataGrid boundary.

**Feature registration beats feature flags (TanStack v9).** v9 turns features
into an explicit object. LUC declares one `dataTableFeatures` constant so the
row models we ship are the row models we render — the same discipline ECharts
gets in the chart layer.

**Do not re-implement a state machine you can rent (Downshift, cmdk).**
`aria-activedescendant` bookkeeping is where hand-rolled comboboxes fail
accessibility audits. Downshift and cmdk already pass those audits; LUC spends
its effort on the surface, the API and the states instead.

**Behaviour and skin are separable (Sonner).** Sonner's CSS-variable theming
surface means we can adopt the motion and gesture handling without inheriting
its visual identity — the same "reuse the engine, own the experience" rule as
the chart round.

**A panel is not a drawer (Vaul).** An unmaintained gesture library is not a
reason to hand-roll focus trapping. Radix Dialog already gave LUC correct focus
trap, restore, Escape and `aria-modal`; the Sheet adds an edge, a size
vocabulary and LUC motion.

## Treasures found while searching

Not a dependency — recorded because they are genuinely useful references for
future rounds:

- **`tanstack/table` v9 `Subscribe`** — per-slice subscriptions. The DataTable
  does not need them yet (it subscribes to the whole state), but a 100k-row
  server table would; it is the documented upgrade path.
- **React Spectrum's collection API** — a vocabulary for describing tables as
  data rather than JSX. Considered for the `DataTableColumn` model; rejected as
  over-abstraction for a formatting-focused API.
- **Glide's "overdraw" idea** — keep the last rendered frame while measuring.
  Not needed at our row counts; noted for a future DataGrid.
- **Base UI's `Menu` composition** — the cleanest public example of an
  unstyled menu with typeahead that we found. Reference for any future
  `ContextMenu`.

## Commands used

```bash
for r in TanStack/table TanStack/virtual downshift-js/downshift emilkowalski/sonner \
         dip/cmdk mui/base-ui ariakit/ariakit tailwindlabs/headlessui \
         adobe/react-spectrum glideapps/glide-data-grid radix-ui/primitives \
         shadcn-ui/ui emilkowalski/vaul; do
  curl -s "https://api.github.com/repos/$r" \
    | jq '{license: .license.spdx_id, stars: .stargazers_count, pushed: .pushed_at, archived}'
done

# installed-package licenses (the ones that actually ship)
node -e "for (const p of ['@tanstack/react-table','@tanstack/react-virtual','downshift','sonner','cmdk']) { const m = require(\`./packages/ui/node_modules/\${p}/package.json\`); console.log(m.name, m.version, m.license); }"
```

Nothing in this audit was copied into `@luc/ui`. Every dependency row uses the
published public API only, and every `REFERENCE_ONLY` row contributed ideas,
not source.
