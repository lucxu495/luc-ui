# Luc UI v1.0.1

Luc UI 1.0.1 is a patch release for the public `@luc/ui` React and TypeScript
design system.

## Highlights

- Official light and dark Luc UI brand assets across the README, Showcase
  navigation, favicon, Apple touch icon and social metadata.
- Clearer installation guidance for React + Vite and Next.js App Router, with
  clean production builds verified outside the pnpm workspace.
- Complete usage, API, data-contract and limitation guidance for canonical
  component, Motion, Chart and TradingView documentation.
- Accessibility corrections for long heading identifiers, compact date/time
  segments and reduced-motion progress indicators.
- Independent verification, clean-consumer, browser QA and Linux visual
  regression jobs in GitHub Actions.

## Installation

```bash
pnpm add @luc/ui@github:lucxu495/luc-ui#v1.0.1
```

```bash
npm install @luc/ui@github:lucxu495/luc-ui#v1.0.1
```

Import Tailwind first, then the Luc UI stylesheet:

```css
@import "tailwindcss";
@import "@luc/ui/styles.css";
```

Wrap the application in `LucProvider`. The package is ESM-only and requires
React 19 and React DOM 19.

## Compatibility

This is a backward-compatible patch. It does not remove or rename a public
export, add a required peer dependency, or change the package entry-point
layout. Existing code can upgrade by changing only the pinned Git tag and
refreshing the lockfile.

## Supported environments

- React and React DOM 19.
- Tailwind CSS v4 for the supplied stylesheet.
- Vite and Next.js App Router production builds.
- Node.js 22 or newer for repository development.

## Known limitations

- The package is distributed through GitHub tags, not npm.
- TradingView widgets require network access and data is supplied by
  TradingView, not Luc UI.
- There is no hosted public Showcase; the full bilingual documentation runs
  locally.

## Release assets

The GitHub Release includes the packed `@luc/ui` tarball, its SHA-256 checksum
and the generated `RELEASE.json` manifest. The `v1.0.1` tag remains the
recommended install because the lockfile records the exact resolved commit.
