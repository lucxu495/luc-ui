# Luc UI v1.2.0

Luc UI 1.2.0 adds a first-class product tour module to the public component
surface.

## Highlights

- `ProductTour` with a full-screen welcome, five-second countdown and smooth
  transition into the first live target.
- Minimal Glass and Soft Cloud Glass bubble variants.
- Collision-aware target placement with flip, shift, nested scrolling and
  target recovery.
- Manual and automatic navigation, pause/resume, progress and cleanup.
- Keyboard focus management, Escape dismissal and reduced-motion handling.
- The `GuidedTour` API remains available and unchanged.

## Installation

```bash
pnpm add @luc/ui@github:lucxu495/luc-ui#v1.2.0
```

```bash
npm install @luc/ui@github:lucxu495/luc-ui#v1.2.0
```

Import from the dedicated entry when the main barrel is not needed:

```tsx
import { ProductTour, type ProductTourStep } from "@luc/ui/product-tour";
```

## Compatibility

This is a backward-compatible minor release. It adds public symbols and a
subpath; it does not remove or rename an existing export, add a required peer
dependency, or change the release-tree layout.

## Supported environments

- React and React DOM 19.
- Tailwind CSS v4 for the supplied stylesheet.
- Vite and Next.js App Router production builds.
- Node.js 22 or newer for repository development.

## Release assets

The GitHub Release includes the packed `@luc/ui` tarball, its SHA-256 checksum
and the generated `RELEASE.json` manifest. The immutable `v1.2.0` Git tag is the
recommended install because the consumer lockfile records the exact release
commit.
