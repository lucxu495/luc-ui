# LUC UI productization audit — verified current state

Date: 2026-10-08. Scope: read-only inspection of `luc-ui` and `luc-web`; this document is an audit artifact, not a change to the package. **Verified** means observed in source or configuration at this revision. **Coverage** identifies a concrete test or Showcase route, not a claim that every variant is tested. The package's prior inventory at `luc-ui/docs/COMPONENT_INVENTORY.md` is useful context but contains historical sections and at least one stale claim (see below).

### Status convention

- **Implemented/public**: exported by the root or a declared subpath, with a source implementation.
- **Partial**: public capability exists but an important adjacent contract is absent or narrower than its name may suggest.
- **Internal**: source exists without an advertised package entry; use public composition instead.
- **Missing**: no public family found in `src/index.ts`, `package.json` or relevant family barrels.
- **Provider-dependent**: public wrapper exists, but provider internals and behavior are outside LUC's control.

### Explicitly internal or absent

`src/components/menu-shared.tsx`, `src/charts/adapters/**` internals and `src/integrations/tradingview/core/**` implementation files are **internal** even though selected helpers are re-exported through public chart/provider barrels (`luc-ui/packages/ui/src/charts/index.ts`, `luc-ui/packages/ui/src/integrations/tradingview/index.ts`). There is **no public DataGrid, editable table, drag/drop docking, multi-select Combobox, standalone chart annotation editor, or chart data computation** in the public barrels. Some of these are deliberate boundaries, not automatic roadmap items (`luc-ui/docs/COMPONENT_INVENTORY.md`, `luc-ui/docs/CHART_GUIDE.md`, `luc-ui/docs/WORKSPACE_GUIDE.md`).

### Documentation drift found during source check

`luc-ui/docs/COMPONENT_INVENTORY.md` says Button has `asChild`, but `ButtonProps` extends native button props and renders `<button>` directly in `luc-ui/packages/ui/src/components/button-base.tsx`. `luc-ui/docs/PUBLIC_API.md` calls all listed entries stable at V1.0; the actual package now includes motion families such as `SharedHighlight`, `MotionSurface` and `MorphingDialog` via `src/motion/index.ts`, while that document's short export list does not enumerate all of them. Treat both documents as guidance and resolve exact API from barrels and props before authoring examples.
